# Statecraft 4.0 prototypes (archived)

These two HTML pages were the S2 look-and-feel prototypes (2026-10-11). They run the real engine
(`assets/engine.js`, built by `scripts/build-proto-engine.mjs`) on a simple three.js globe.

They are **superseded** by the game inside the app, which uses the real 1.0 globe:

- Play page: `/play` (`components/game/PlayLanding.tsx`)
- Match: `/play/match` (`components/game/PlayScreen.tsx`)
- Shared results: `/play/h/[code]`

Keep this folder only as a design reference. Do not add features here.
